# Data and model distribution

The code repository is public. The `xl_r16_multidata_5060_v1` model Release was changed to a recoverable draft on 8 November 2026; its adapter archive and checksum asset were retained. Drafting does not revoke previously downloaded copies or constitute licence clearance.

Do not republish model assets or generated prediction/SFT data until applicable terms and permissions have been reviewed. There is no blanket redistribution clearance for the mixed-source adapter. This is an unresolved permission check, not a conclusion that a particular data licence necessarily applies to model weights.
